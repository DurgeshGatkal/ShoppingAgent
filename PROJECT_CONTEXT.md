# BuySense AI

## Project Goal
BuySense AI is an AI-powered Shopping Decision Agent that helps users make smarter purchasing decisions.

## Tech Stack
- Python
- Streamlit
- Gemini API
- SQLite
- BeautifulSoup
- Pandas

## Current Features
- Product Search
- Product Comparison
- AI Recommendation
- Product Details
- AI Chatbot

## Target Features
- Search products from multiple websites
- Compare price, ratings, reviews and delivery
- AI-generated buying recommendation
- AI chatbot for answering product-related questions
- Redirect users to original product pages
- Professional UI
